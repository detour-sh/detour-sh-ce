# Detour Community Edition

See `CONTRIBUTING.md` for setup, tests and UI rules. Dev environment: `.claude/dev-env.md`.

- Do not use Linear for Detour: no issues, no project updates, no questions about it. Track work in git (commits and CHANGELOG). Design decisions are recorded by the maintainers outside this repo; don't add decision records here.
- Versioning: every release is a patch bump. Don't pick a minor or major version unless the owner asks for it; you may suggest one, with the reason. Don't release after each PR: leave entries under `[Unreleased]` until the owner asks for a release.
