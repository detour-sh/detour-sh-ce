# Detour Community Edition

See `CONTRIBUTING.md` for setup, tests and UI rules. Dev environment: `.claude/dev-env.md`.

- Do not use Linear for Detour: no issues, no project updates, no questions about it. Detour is unrelated to the MOU team and its repo. Track work in git (commits, CHANGELOG, `docs/decisions/`).
- Versioning (`docs/decisions/0002-patch-releases-by-default.md`): every release is a patch bump. Don't pick a minor or major version unless the owner asks for it; you may suggest one, with the reason. Don't release after each PR: leave entries under `[Unreleased]` until the owner asks for a release.
